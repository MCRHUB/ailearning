## 复习建议

1. **先做预测题**：[考试预测题](TestForecast.md) 覆盖高频考点，可作为自测起点
2. **刷单选题库**：两套单选题库合计 200+ 道，覆盖大部分知识点
3. **攻克多选题**：多选题是拉分关键，重点关注 [多选题库](TestPaper3.md) 中的考试提示
4. **准备简答题**：[工程实践题](TestProject.md) 提供了答题思路和范例，建议自己先写再对照
